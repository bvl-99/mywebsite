# valentinbordea.com

Personal portfolio of Liviu-Valentin Bordea — built with [SvelteKit](https://svelte.dev/docs/kit) (Svelte 5, TypeScript), prerendered to static files and hosted on GitHub Pages.

No CSS framework, no jQuery, no analytics, no cookies. Styling is plain CSS driven by design tokens.

## Develop

```sh
npm install
npm run dev        # http://localhost:5173
npm run check      # type + Svelte checks
npm run build      # static site into ./build
npm run preview    # serve ./build locally
npm run format     # Prettier
```

Requires Node 20.19+ (Node 22 LTS recommended).

## Where things live

## Adding a project

1. Put the image(s) in `static/assets/img/` (WebP, ideally under ~100 KB).
2. Add an entry to the `projects` array in `src/lib/content/projects.ts` (the file explains each field).
3. That's it — the list page, detail page, home "Featured" grid (`featured: true`) and `sitemap.xml` update automatically.

New category or page? Add a route in `src/routes/`, give it an `<Seo …/>` component for its title/description, and add its path to `src/routes/sitemap.xml/+server.ts`.

## SEO

Every page renders `<Seo>` (`src/lib/components/Seo.svelte`): title, description, canonical URL, Open Graph and Twitter tags. The home page also adds `Person` structured data. `sitemap.xml` is generated at build time; `robots.txt` is in `static/`. The default social preview image is `static/assets/img/seo-social-banner.jpg` (1200×630).

## Contact form

The form posts to [Formspree](https://formspree.io) (endpoint in `src/lib/site.ts`; the ID is public by design, not a secret). It includes a honeypot field and works without JavaScript (plain form post). In the Formspree dashboard, restrict submissions to `valentinbordea.com` and turn on its spam filtering.

## Deployment

Pushing to `main` runs `.github/workflows/deploy.yml`: `npm ci` → `npm run check` → `npm run build` → deploy `build/` to GitHub Pages. The custom domain is configured in the repository's **Settings → Pages**; "Enforce HTTPS" should stay on. Unknown URLs get `404.html` (generated by the static adapter).

## Analytics

Optional, cookieless analytics via [Umami Cloud](https://umami.is). Create a site there, copy its **Website ID**, and paste it into `analytics.websiteId` in `src/lib/site.ts`. Leave it empty to disable analytics (the script is then not loaded and the privacy page says so).

Tracked clicks use `data-umami-event="…"` attributes on links and buttons (`download-cv`, `project-open`, `social-click`, `hero-get-in-touch`, `hero-view-work`); a successful contact-form send is tracked as `contact-submitted`. Add the same attribute to any new link or button to see it under **Events** in Umami.

## Privacy

The site sets no cookies. Roboto is self-hosted (SIL Open Font License, see `static/assets/fonts/OFL.txt`); social icons are Font Awesome Free (CC BY 4.0). If you add anything else third-party (embeds, other trackers), update `src/routes/privacy/+page.svelte` first and add consent where required.
